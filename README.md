# Займовик

Внутренний репозиторий данных и отчётов проекта «Займовик».

## Как будет работать

1. Агрегированный CSV из Keitaro сохраняется в [`data/weekly/`](data/weekly/).
2. Генератор из [`scripts/`](scripts/) проверяет показатели и строит таблицы и графики.
3. Готовый отчёт появляется в [`reports/`](reports/) и открывается прямо в GitHub.
4. Значения и формулы показателей хранятся в [`metrics.md`](metrics.md).

## Настройки выгрузки Keitaro

- Период: последние 30–35 дней.
- Часовой пояс: UTC.
- Фильтры: отсутствуют, чтобы получать всех партнёров.
- Группировки: День → Источник → Кампания.
- Формат: CSV.

## Безопасность

В репозиторий нельзя добавлять пароли, cookies, session ID, API-ключи, IP-адреса пользователей и другие персональные или авторизационные данные. Сохраняются только агрегированные отчёты.
