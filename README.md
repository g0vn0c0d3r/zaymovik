# Займовик

Внутренний репозиторий аналитики проекта «Займовик».

## Разделы

- [`analytics/`](analytics/) — настройки отчёта Keitaro, справочник метрик и еженедельные выгрузки.

## Безопасность

В репозиторий нельзя добавлять пароли, cookies, session ID, API-ключи, IP-адреса пользователей и другие персональные или авторизационные данные. Для аналитики сохраняются только агрегированные отчёты.
