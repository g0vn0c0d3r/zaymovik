# Аналитика

## Настройки отчёта Keitaro

- Период: последние 30–35 дней.
- Часовой пояс: UTC.
- Фильтры: отсутствуют, чтобы получать всех партнёров.
- Группировки: День → Источник → Кампания.
- Источник и кампания сейчас обозначают партнёра; после проверки всех партнёров дублирующую группировку можно убрать.
- Формат выгрузки: CSV.

## Еженедельный процесс

1. Открыть сохранённый отчёт Keitaro.
2. Выбрать последние 30–35 дней и обновить отчёт.
3. Экспортировать CSV.
4. Сохранить агрегированную выгрузку в `data/weekly/` с именем `keitaro_YYYY-MM-DD_YYYY-MM-DD.csv`.
5. Обновить справочник [`metrics.md`](metrics.md), если была согласована новая метрика.

Сырые логи кликов с IP, User-Agent и идентификаторами пользователей сюда не добавляются.
